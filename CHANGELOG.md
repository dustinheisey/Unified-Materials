# Changelog

## [0.3.0](2026-02-23)

### Features

* rewrote the mod to be a jar plugin.
* removed elements that are gaseous at room temperature and removed the ingots for elements that are liquid at room temperature. I will add liquids and gases in a future update.
* updated the colors for all textures to be more realistic. I still don't fully like them so I will keep updating over time.
* added the atomic numbers, prefixes and groups to each element tooltip description.
* removed recipes for ingots, alloys and dusts, and removed the opinionated descriptions about how to get those things in their tooltips. This is so this mod can be more of a library that other * * mods can decide how to use them, their tooltip descriptions and what recipes make sense for their project.
* updated to the latest server version

## [0.2.0](2026-02-03)

### Features

* added ores, dusts, and ingots to all 118 atomic elements
* added 12 new gems
* added 19 new alloys
* added recipes for all ores to be ground into dusts at a salvager's workbench
* added recipes for smelting all ores and dusts into ingots in a furnace
* added recipes for all alloys in a tier 2 furnace
