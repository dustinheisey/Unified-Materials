# Unified Materials

This plugin currently adds materials that can help other mods construct recipes and mechanics without needing to recreate the same ore/ingot for the 100th time. These materials are based in chemistry and materials science and are suited for mods going for a realism aesthetic.

Currently it provides the following:

- Ores encased in Basalt, Sandstone, Stone, Shale, Slate, and Volcanic Rock for all metallic atomic elements
- 21 realistic gemstones
- 32 realistic alloys

This plugin was made using [hytale-generators](https://www.npmjs.com/package/hytale-generators) with the [Hytale Generators Plugin Starter](https://github.com/dustinheisey/Hytale-Generators-Plugin-Starter). It can be downloaded on [Curseforge](https://www.curseforge.com/hytale/mods/unified-materials)
